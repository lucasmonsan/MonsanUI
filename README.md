# MonsanUI

MonsanUI is the private Svelte 5 component library used by the Monsan app suite.

Its job is simple: keep Examster, Manki and Owlth visually consistent without forcing each app to redefine layout, spacing, colors, controls, dialogs or common interaction patterns.

## What It Provides

- Styled Svelte 5 components exported from `src/lib`.
- Shared CSS tokens in `monsan-ui.css` and `variables.css`.
- A local showcase app in `src/routes`.
- Package output generated with `svelte-package`.
- Strict lint, typecheck, build and package validation through `pnpm test`.

## Usage In Apps

Consumer apps install MonsanUI from the private GitHub repository:

```bash
pnpm add "git+ssh://git@github.com/lucasmonsan/MonsanUI.git#main"
```

Import the shared styles once in the app CSS or root layout:

```ts
import 'monsan-ui/monsan-ui.css';
```

Then import components directly:

```svelte
<script lang="ts">
	import { Button, Stack, Alert } from 'monsan-ui';
</script>
```

## Updating Consumers

After changing MonsanUI and merging it into `main`, update each consumer app with:

```bash
pnpm update monsan-ui
pnpm test
```

`package.json` tracks `#main`; `pnpm-lock.yaml` pins the exact commit used by each app.

## Local Commands

```bash
pnpm install
pnpm test
pnpm build
pnpm run build:package
pnpm run lint:package
```

`pnpm test` is the full gate:

```bash
pnpm lint && pnpm typecheck && pnpm build && pnpm run build:package && pnpm run lint:package
```

## Generated Files

Do not commit generated output:

- `build`
- `dist`
- `.svelte-kit`
- `node_modules`

`dist` is generated by `prepare` when consumer apps install the package.

## Environment

MonsanUI does not require a `.env` file.

## Deployment

The showcase is a static SvelteKit app. In Coolify, use the static output generated by the build. Consumer apps must have GitHub/SSH access to this private repository during install.

## Before Merging

Run:

```bash
pnpm test
```
